# 复制提示

按下 ⌘C 之后，屏幕底部轻轻弹一句「复制成功，快去粘贴吧」，两秒后自己消失。

![复制提示弹出时的样子](docs/preview.png)

专治那种「我刚才是复制了吗？」的瞬间犹豫。它住在菜单栏，不占程序坞、不抢焦点、不打扰你干活。

## 安装

### 方式一：下载现成的（推荐）

1. 打开 [Releases](https://github.com/xzx1003/copy-toast/releases/latest)，下载 `CopyToast-1.0.0.zip`
2. 解压，把 `复制提示.app` 拖进「应用程序」文件夹
3. 双击打开

第一次打开时 macOS 可能会拦一下，提示「无法验证开发者」——因为这个 app 没做苹果的付费签名，属于正常现象。放行一次就好：

- 在「应用程序」里**右键**点它 → 选「打开」→ 再点一次「打开」
- 如果右键也没用，去「系统设置 → 隐私与安全性」，页面往下拉，会有一段关于「复制提示」的说明，点「仍要打开」

放行一次之后，以后正常双击就能开。

### 方式二：自己编译

见文末「从源码构建」。

## 打开之后

菜单栏会多出一个 📋，同时屏幕上先弹一次「复制提示已开启」——说明它已经工作了。

之后你复制任何东西，都会看到那句提示。点一下 📋，菜单里有这几项：

| 菜单项 | 用途 |
|---|---|
| 剪贴板检测已开启 | 只是个状态标签，不是按钮 |
| 开启辅助功能权限… | 开了检测更准，不开也能用 |
| 测试提示 | 手动弹一次，确认显示正常 |
| 开启输入监控权限… | 同上，可选 |
| 退出（⌘Q） | 关掉它 |

## 它怎么知道你复制了

它盯着剪贴板：内容一变化，就认为你复制了东西，于是弹提示。

好处是不挑方式——⌘C、右键菜单、从别的应用拖进来，都能触发。

代价是这几种情况会有偏差，先说清楚：

- **复制一模一样的内容，可能不弹。** 系统认为「没变化」，剪贴板没有更新，它也就无从得知。
- **别的应用改了剪贴板，也可能弹。** 比如手机剪贴板同步过来的时候。
- **它不读取、不保存、不上传你复制的内容。** 只关心「变了没有」，不关心变的是什么。

## 常见问题

**打开了，但复制没反应？**
先点菜单里的「测试提示」。能弹出来，说明显示没问题，卡在检测环节——去「系统设置 → 隐私与安全性 → 辅助功能」把「复制提示」勾上，然后退出重开。

**想让它开机自动启动？**
「系统设置 → 通用 → 登录项」，点 ＋，选「应用程序」里的「复制提示」。

**怎么彻底删掉？**
菜单里点「退出」，再把「应用程序」里的「复制提示.app」拖进废纸篓。

## 从源码构建

需要先装 Xcode 命令行工具：

```sh
xcode-select --install
```

然后在仓库目录里执行：

```sh
zsh build.sh
```

会在当前目录生成 `复制提示.app`，同时包含 Apple Silicon 和 Intel 两个架构。首次运行同样需要按上面的方法放行一次。

## 其他

- 系统要求：macOS 13 或更高
- 整个程序只有一个 Swift 文件（`main.swift`），没有第三方依赖，也不联网
- 想换提示语、改字号或停留时间，改 `main.swift` 里的 `toast(...)` 和 `asyncAfter(deadline: .now() + 2)` 即可
- `--snapshot 路径.png` 可以让程序把自己的提示面板存成图片，README 顶部那张预览图就是这么生成的
- 有问题或想法，欢迎提 [Issue](https://github.com/xzx1003/copy-toast/issues)
