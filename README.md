# 复制提示

一个轻量的 macOS 菜单栏工具。检测到剪贴板内容变化时，在屏幕底部短暂显示「复制成功，快去粘贴吧」。它不保存剪贴板内容。

## 使用

双击 `复制提示.app` 启动。菜单栏出现 📋 后，复制文字即可看到提示。菜单中的「测试提示」可以单独检查弹框显示。

工具通过剪贴板变化判断复制，因此右键复制也可以触发；剪贴板同步或其他应用更新剪贴板也可能触发。复制相同内容时，macOS 或目标应用可能不会更新剪贴板，因此无法保证每次 Command+C 都显示提示。

## 从源码构建

需要 macOS 和 Apple Command Line Tools：

```sh
zsh build.sh
```

脚本会在仓库根目录生成 `复制提示.app`。首次运行若 macOS 提示安全确认，请在系统设置中允许打开。

## 当前支持

- macOS：菜单栏应用，使用 Swift 和 AppKit。
- Windows：暂未提供。
